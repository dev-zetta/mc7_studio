# MC7 Studio 0.2.1

Released 2026-10-27.

This update fixes custom surface calibration, application icons and 8 kHz configuration for the Command Series MC7. Upgrade from 0.2.0 to get these fixes.

## Fixes

- Surface calibration enables completion notifications, allows up to five minutes for movement and keeps both wireless Save packets in one reporting pause. Save still requires explicit acceptance and verified readback in all five profiles.
- Changing an application icon or label refreshes its LCD tile immediately. Replacing a shared icon preserves the other tile, and applying an unchanged icon avoids another upload.
- Wireless 8 kHz polling-rate changes restore the receiver's configuration handshake before reading settings back. Status reads, live-value updates and background transfers also use the paired receiver handshake.
- Specialized LCD reads check the requested profile and page before accepting a receiver reply.

## Validation

The local automated suite passed 1,331 tests. On Linux with mouse firmware 5.09, custom calibration completed, saved and read back in all five profiles over USB and 2.4 GHz at the 4 kHz setting. Tracking felt normal when moving, lifting and repositioning; the original Low preset, supported settings and assigned macros were restored and verified afterward.

Wireless application-icon upload, sharing, replacement, rendering and application launch were checked at 4 kHz. Wireless 8 kHz configuration, readback and pointer responsiveness were checked; effective report frequency and latency have not been measured.

## Downloads and limits

Packages are available for Linux x86_64 (AppImage, glibc 2.35 or newer), Windows x86_64 (portable ZIP), and Apple Silicon Macs (ZIP, macOS 13 or newer). Python wheel, source distribution, corresponding sources and checksums are included.

Linux 2.4 GHz support remains broader than the macOS and Windows connection support, which requires direct USB. Physical MC7 acceptance on macOS and Windows, calibration at 8 kHz and long-running wireless LCD services remain pending. Firmware installation requires a direct USB connection. Continue to choose ECO mode or energy saving individually in wireless mode.
